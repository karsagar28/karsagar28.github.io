  <p class="eyebrow">About</p>
  <h1>Make the running knowledge persistent.</h1>

  **copy run start** is a collection of questions and working notes about networking. The goal is not to repeat a specification, but to build explanations that make protocols easier to reason about and operate—and save the insights that should survive the next reload.

  Topics will include Ethernet, data-center networking, congestion control, RoCE, and whatever question is interesting enough to investigate next.

  These are living notes. If you spot an error or have a useful counterexample, corrections are welcome through [GitHub](https://github.com/karsagar28/karsagar28.github.io/issues).
